# Random Color Generator 🎨

A simple and beginner-friendly Random Color Generator built with HTML,
CSS, and JavaScript.

## Live Demo

[Live Demo](https://github.com/shaheerarain44-coder/Color-Generator.git)

## Features

-   Generate a random HEX color.
-   Change the color box background.
-   Display the generated color code.
-   Copy the current color code.
-   Show a temporary "Copied!" message.
-   Responsive design for mobile devices.

## Technologies Used

-   HTML5
-   CSS3
-   JavaScript
-   DOM Manipulation
-   Clipboard API
-   `setTimeout()`
-   `Math.random()`

## How It Works

1.  Click the **Generate Color** button.
2.  JavaScript creates a random HEX color.
3.  The color box background changes.
4.  The generated HEX code appears on the page.
5.  Click **Copy** to copy the color code.

## How to Run

1.  Download or clone this repository.
2.  Open the project folder in VS Code.
3.  Open `index.html` in your browser.
4.  Click **Generate Color** to create a new color.
